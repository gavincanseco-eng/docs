## Get Started in Four Steps

You can go from a blank Linux server to a fully tuned Minecraft instance in under an hour. The steps below follow the same order as the rest of this guide — complete them in sequence for best results.

<Steps>
  <Step title="Check Requirements">
    Confirm your server meets the minimum hardware and software requirements before installing anything. Pay close attention to the recommended Java 21 version and Linux kernel baseline documented in the [Requirements](/requirements) page.
  </Step>
  <Step title="Install Paper">
    Download the latest Paper 1.21.1 build, accept the EULA, and verify the server starts cleanly before applying any configuration changes. The [Paper Setup](/server-software/paper) page covers the full installation process including recommended JVM flags for Java 21.
  </Step>
  <Step title="Apply Configuration">
    Work through each configuration file — `server.properties`, `bukkit.yml`, `spigot.yml`, and `paper-global.yml` — using the recommended values from the [Configuration](/configuration/server-properties) page. Every setting is explained so you understand the trade-off you are making.
  </Step>
  <Step title="Tune the OS">
    Apply the Linux network and kernel tuning parameters described in the [OS & Network](/optimization/linux-network) page. These changes persist across reboots and deliver the final layer of latency reduction that no software-level tweak can replicate.
  </Step>
</Steps>
