`paper-global.yml` is generated by Paper in the server root directory on first run. It controls global settings that apply across all worlds. Unlike `server.properties`, this file exposes Paper-specific internals — chunk I/O threading, packet limiting, and player data handling — that have a direct impact on main-thread tick time and network resilience.

```yaml paper-global.yml
_version: 29

chunk-system:
  gen-parallelism: default        # auto-tunes to CPU core count
  io-threads: -1                  # -1 = auto (uses dedicated I/O thread pool)

network:
  kick-bad-packet-data: true      # Boot clients sending malformed packets
  max-joins-per-tick: 3           # Limit simultaneous join spam

packet-limiter:
  all-packets:
    action: DROP
    max-packet-rate: 500.0
  overrides:
    ServerboundPlaceRecipePacket:
      action: DROP
      max-packet-rate: 20.0

playerdata:
  async-save: true                # Save playerdata off the main thread

timings:
  enabled: false                  # Disable Timings — use Spark instead
  server-name: ServerHoster

spawnlimits:
  monsters: 70                    # Vanilla default is 70 — lower to 50 for perf
  creatures: 10
  ambient: 15
  axolotls: 5
  underground_water_creature: 5
  water_creature: 5
  water_ambient: 20

item-validation:
  book:
    author: 8192
    page: 16384
    title: 8192
  resolve-selectors-in-books: false
```

## Key Settings Explained

These are the settings that have the largest impact on performance and security. The remaining keys control edge-case behaviour and are safe at their defaults.

| Setting | Value | Reason |
|---|---|---|
| `network.kick-bad-packet-data` | `true` | Drops clients abusing protocol |
| `network.max-joins-per-tick` | `3` | Prevents join-flood lag spikes |
| `packet-limiter` | configured | Caps packet rate to prevent packet-flood attacks |
| `playerdata.async-save` | `true` | Player saves happen off-main-thread |
| `timings.enabled` | `false` | Timings has overhead; use Spark for profiling |
| `chunk-system.io-threads` | `-1` | Auto-scale I/O pool to hardware |

<Note>
  The `paper-global.yml` file is located in your server root (same directory as `server.jar`). Restart the server after any changes.
</Note>

<Tip>
  Lower `spawnlimits.monsters` to `50` if you are running a high-player-count server — this reduces entity tick budget significantly.
</Tip>
